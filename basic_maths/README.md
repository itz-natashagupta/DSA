# 🔢 Basic Maths Programs in C++

A collection of fundamental number theory and math programs written in C++ as part of my DSA learning journey.

---

## 📁 Folder Structure

```
basic_maths/
├── 01_count_digits.cpp           → Count all digits in a number (2 ways)
├── 02_count_odd_digits.cpp       → Count odd digits in a number
├── 03_reverse_number.cpp         → Reverse a number
├── 04_palindrome.cpp             → Check if a number is Palindrome
├── 05_largest_digit.cpp          → Find the largest digit in a number
├── 06_factorial.cpp              → Factorial (Recursion + Iterative)
├── 07_armstrong.cpp              → Check if a number is Armstrong
├── 08_perfect_number.cpp         → Check if a number is Perfect
├── 09_prime_number.cpp           → Check if a number is Prime
├── 10_sieve_of_eratosthenes.cpp  → Print all Primes up to N (Sieve)
├── 11_gcd.cpp                    → Greatest Common Divisor (GCD)
├── 12_lcm.cpp                    → Lowest Common Multiple (LCM)
└── 13_divisors.cpp               → Print all Divisors of a number
```

---

## 📋 Program Descriptions

| # | Program | Description | Example |
|---|---------|-------------|---------|
| 01 | Count Digits | Count total digits in a number | `12345` → `5` |
| 02 | Count Odd Digits | Count only odd digits | `12345` → `3` (1,3,5) |
| 03 | Reverse Number | Reverse digits of a number | `12345` → `54321` |
| 04 | Palindrome | Check if number reads same both ways | `121` → Yes ✅ |
| 05 | Largest Digit | Find the biggest digit | `3829` → `9` |
| 06 | Factorial | Product of all numbers from 1 to n | `5!` = `120` |
| 07 | Armstrong | Sum of digit^n equals the number | `153` → Yes ✅ |
| 08 | Perfect Number | Sum of divisors equals number | `6` → Yes ✅ |
| 09 | Prime Number | Only divisible by 1 and itself | `7` → Yes ✅ |
| 10 | Sieve of Eratosthenes | Find all primes from 2 to N | N=10 → `2 3 5 7` |
| 11 | GCD | Greatest Common Divisor | GCD(12,18) = `6` |
| 12 | LCM | Lowest Common Multiple | LCM(4,6) = `12` |
| 13 | Divisors | All numbers that divide N | `12` → `1 2 3 4 6 12` |

## ⚙️ How to Compile & Run

```bash
g++ 01_count_digits.cpp -o output.exe
./output.exe
```

Or open in **VS Code** and press `Ctrl+Shift+B` to build and run the active file.
