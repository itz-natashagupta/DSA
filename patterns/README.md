## ⚙️ How to Compile & Run

Make sure you have `g++` installed. Then:

```bash
g++ pattern1.cpp -o pattern1.exe
./pattern1.exe
```

Or open in **VS Code** and press `Ctrl+Shift+B` to build and run the active file.
